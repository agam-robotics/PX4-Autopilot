1.
Parameters or the provision of definition of
BOARD_BATTERY_ADC_VOLTAGE_FILTER_S 0.075f and
BOARD_BATTERY_ADC_CURRENT_FILTER_S 0.125f
for analog voltage and current filtering is removed after v1.17.0.

v1.17.0 onwards you will find below parameters added instead which can be controlled using paramater settings
BAT1_I_FILT
BAT1_V_FILT

you can add below lines in the default parameter list under init folder.
param set-default BAT1_V_FILT 0.075
param set-default BAT1_I_FILT 0.5
